Pick the model that fits you

From a 40 MB English model to 7B long-audio models: Qwen3-ASR, SenseVoice, Parakeet, Whisper-style OWSM, Moonshine and more. Download only what you need, with resumable downloads, SHA-256 checks and mirror sources.

  • Chinese, Cantonese, English, European and low-resource languages
  • Streaming, word timestamps and speaker-aware models
  • Hugging Face, ModelScope and HF mirror sources

One request to transcribe

While the app is open it serves a local HTTP API that shares the same queue as the UI.

# SRT subtitles from a local file
curl -H 'Content-Type: application/json' \
  -d '{"path":"/abs/talk.m4a","format":"srt"}' \
  http://127.0.0.1:7895/transcribe
